# Avoid Trend Memes

Unity 6000.0.43f1로 만드는 가로 화면의 2D 밈 장애물 회피 게임.
타이틀 화면 표시 이름은 **최신 밈 피하기**이다.
Unity 프로젝트 폴더는 `Avoid Trend Memes`이며, GitHub 저장소는 `Avoid-Trend-Memes`이다.
해커톤에서는 PC로 실행하며, 모바일 기기 배포와 터치 입력은 현재 범위에서 제외한다.
이전 퍼즐 전투 기획은 폐기하고 아래 기획을 기준으로 개발한다.

## 게임 기획

- 한 화면에서 함정과 레이저 등 장애물을 피한다.
- 키보드 좌우 화살표로 이동하고 스페이스바로 점프한다. 공중에서 한 번 더 눌러 더블 점프할 수 있고, 착지하면 점프 횟수가 초기화된다.
- 플레이어의 시작 HP는 5이며, HP가 소진되면 게임오버 후 타이틀 화면으로 돌아간다.
- 타이틀 화면에서 새 게임을 시작할 수 있다.
- 단계는 랜덤하게 등장하며, 단계 클리어마다 힐팩을 제공한다.
- 장애물은 67 밈, L을 가져와 밈, 한남 말투 밈 등을 소재로 한다.
- 부드러운 애니메이션과 효과음을 주요 완성도 기준으로 삼는다.
- 현재 소리는 사용자가 직접 준비하므로 효과음을 생성하거나 재생하지 않는다.
- 장애물을 피하는 플레이 시간 0.1초마다 1점(초당 10점), 스테이지 클리어마다 100점. 로딩·힐팩 대기·게임오버 중에는 시간 점수를 얻지 않는다.
- 힐팩 수령 후에는 별도 대기 없이 다음 스테이지를 시작하고, 플레이어 위치·속도·점프 상태를 유지한다.
- 게임오버와 타이틀 복귀 시 등급 옆에 최종 점수를 표시한다. 기준: SS 1000점 이상, S 800, A 600, B 400, C 300, D 200, E 100, F 100점 미만.

## 스테이지 직접 편집

- `Assets/Game/Layouts/Stage0Layout.prefab`(67), `Stage1Layout.prefab`(L), `Stage2Layout.prefab`(말풍선)을 더블 클릭하여 Prefab Mode에서 발판을 이동·복제한다.
- 발판은 `SpriteRenderer`, `BoxCollider2D`, Layer 8을 유지한다. 바닥과 화면 벽은 공통 씬에 남아 있다.
- 발판의 `OneWayPlatform` 컴포넌트는 `PlatformEffector2D`를 설정하여 아래에서는 통과하고 위에서는 착지하게 한다. 기존 발판을 복제하면 이 설정도 복사된다. 새 발판에는 `OneWayPlatform`을 추가한다. 공통 바닥과 벽은 양방향 충돌을 유지한다.
- `Assets/Game/Stages/Stage0.asset`부터 `Stage2.asset`까지 Inspector에서 단계 시간·공격 간격·예고 시간·투사체 속도를 조절한다. L 단계의 `Laser Position`과 `Laser Size`도 직접 수정할 수 있다.
- Layout Prefab에 지정된 프리팹은 해당 단계에서만 표시한다. 프리팹이 없으면 공통 기본 발판을 사용한다.
- 발판 배치는 프리팹, 기존 레이저 좌표·크기는 Stage 에셋, 새로운 공격 동작은 `Assets/Scripts/MemeDodge/GameController.cs`의 `Attack` 메서드에서 수정한다.

## 사용할 기술

- DOTween: 이동, 확대·축소, 페이드 등의 연출.
- UniTask: 대기, 로딩 및 비동기 처리.
- R3: HP와 게임 상태 변경을 UI 등에 연결.
- VContainer: 객체 의존성 연결.
- Addressables: 이미지, 프리팹, 사운드의 로딩과 해제.

## 참고 이미지에서 확인한 화면 기준

- 모바일 가로 화면을 참고한 16:9 화면을 기준으로 한다.
- 검정 배경에 `#DFFF06` 선과 글자를 사용한다. 참고 이미지의 청록색은 사용자가 지정한 색으로 변경한다.
- 참고 이미지의 터치 버튼 대신 화면 하단에 키보드 조작 안내를 배치한다.
- HP는 오른쪽 상단에 표시한다. 이번 게임의 최대 HP는 5이다.
- 타이틀 화면에 게임 이름과 시작하기 버튼을 표시한다.
- 한 화면 안에서 캐릭터와 장애물을 읽기 쉽게 배치한다.

## 구현 및 검증 순서

1. 필수 패키지를 설치하고 Unity에서 컴파일 및 연결 상태를 확인한다.
2. 가로 화면과 키보드 이동·점프를 구현한다.
3. HP 5, 피격 처리, 게임오버, 타이틀 복귀와 새 게임 시작을 구현한다.
4. 밈별 장애물 단계를 구현하고 랜덤 진행과 클리어 힐팩을 연결한다.
5. DOTween 연출과 효과음을 이동, 점프, 피격, 회복, 클리어, UI에 연결한다.
6. Addressables 로딩·해제와 화면 전환 중 취소 처리를 확인한다.
7. PC 실행에서 이동·점프 동시 입력, 16:9 화면 비율, 게임 재시작을 검증한다.

## 아직 결정할 항목

- 클리어 후 힐팩은 바닥에서 더블 점프로 도달할 수 있는 높이와 화면 안의 랜덤 좌표에 생성된다. 직접 닿으면 HP 1을 회복하고 다음 단계로 넘어가며, 최대 HP는 5이다.
- 현재 단계는 18초 생존하면 클리어된다. 피격 후 무적 시간은 1초이며, 다음 단계는 직전 단계와 겹치지 않게 랜덤 선택한다.

위 내용은 기획 기준이며, 기능이나 패키지 설치 완료를 의미하지 않는다.

## 현재 개발 상태

- UniTask 2.5.11과 VContainer 1.19.0 설치를 Unity Pipeline의 패키지 상태에서 확인했다.
- `Assets/Scripts/MemeDodge`에 키보드 입력과 가속·감속·점프 버퍼를 사용하는 플레이어 이동 코드를 추가했다.
- Unity 재컴파일 상태는 completed로 확인했다.
- Addressables 4.1.0과 NuGetForUnity 4.5.0 설치를 확인했다. 공식 DOTween 1.3.030 에셋도 추가했다.
- Play 모드에서 키 입력에 따른 실제 이동, 공중 두 번째 점프와 세 번째 점프 차단을 검증했다.
- R3 1.3.1과 NuGet 의존성 복원 파일을 확인했다.
- `Assets/Scenes/AvoidTrendMemes.unity`에 타이틀, 플레이 화면과 세 가지 밈 장애물을 구성했다.
- 플레이 중 점수, 클리어 보너스와 게임오버 등급을 구현했다. 점수 계산 및 모든 등급 경계값 검사가 통과했다.
- 실제 플레이에서 클리어, 힐팩 충돌 회복, 다음 단계 시작과 게임오버 후 타이틀 복귀를 확인했다.
- DOTween으로 장애물 이동, 예고선, 점프·착지 반동, 이동 기울기와 피격 깜빡임을 구현했다.
- 사용자가 직접 준비할 그림은 아직 임시 도형으로 표시한다. 소리는 생성·로딩·재생하지 않는다.
